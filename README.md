# Hashtag Social

Hashtag Social is a responsive social media concept originally developed for the CSS Frameworks course at Noroff.

The project was built using HTML, CSS, JavaScript and Bootstrap. The goal was to create a responsive social platform where users can browse content, create posts and interact with a profile page while following modern responsive design principles.

For Portfolio 2, I revisited the project to improve the visual presentation, user experience and overall quality of the interface.

## Project Overview

The application consists of three main pages:

### Authentication Page

The landing page contains registration and login forms with client-side validation and a responsive layout.

### Feed Page

The feed acts as the main content area where users can:

* Create new posts
* Search existing posts
* View published content
* Like posts
* Comment on posts

Posts are stored locally using localStorage.

### Profile Page

The profile page displays:

* User information
* Followers and following statistics
* User-created posts
* Profile editing functionality

## Portfolio 2 Improvements

When revisiting the project for Portfolio 2, I focused on improving the overall user experience and presentation rather than rebuilding the project from scratch.

Improvements included:

* Redesigned feed layout
* Improved profile page presentation
* Better content hierarchy and spacing
* Improved responsiveness across screen sizes
* Added like functionality
* Added comment functionality
* Refined visual consistency throughout the application

The goal was to transform the project from a course submission into a stronger portfolio piece.
